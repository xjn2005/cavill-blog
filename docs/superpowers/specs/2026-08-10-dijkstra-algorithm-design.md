# 迪杰斯特拉算法博客设计

## 目标

为算法初学者写一篇中文 Markdown 博客，以正确性证明为主线讲清迪杰斯特拉算法。读者读完后应能理解算法为何正确、何时可用，并能读懂和运行 Python 实现。

## 范围

文章讨论带非负边权的单源最短路径问题，包含：问题模型、松弛操作、贪心不变量及反证法证明、使用基础语法实现的 Python 版本、手工示例、复杂度分析，以及负权边的限制与 Bellman–Ford 的适用场景。

文章不讨论路径计数、多源最短路径、全源最短路径或动态更新图。

## 结构

1. 用导航场景引入最短路径问题，并定义图、边权与单源最短路径。
2. 说明松弛操作和暂定距离，提出贪心选择：每次确定暂定距离最小的未确定节点。
3. 陈述不变量：被确定节点的暂定距离等于真实最短距离；用反证法证明，并指出边权非负是证明成立的前提。
4. 从证明推导算法流程，解释距离表、已确定节点集合，以及通过普通循环寻找最小暂定距离节点的过程。
5. 给出不依赖 `heapq` 的可直接运行 Python 代码，并逐段映射到上述概念。
6. 通过一个小图演示节点确定和距离更新的过程。
7. 总结时间复杂度为 O(V² + E)，并说明负权边应改用 Bellman–Ford 算法。

## 验收标准

- Frontmatter 与现有 Astro 内容集合兼容，文章位于 `src/content/posts/`。
- 中文排版遵守中英文、数字与标点的间距规范。
- 代码仅使用基础 Python 语法，不依赖 `heapq`，且示例输出与文章结论一致。
- 明确写出「不能处理负权边」，避免将适用范围表述得过宽。

## 自检

设计没有待定项或超出目标的主题；证明、实现和示例均围绕「非负权单源最短路径」这一前提，验收标准可直接验证。
