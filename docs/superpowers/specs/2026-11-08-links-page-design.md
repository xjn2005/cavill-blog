# Links 友链页设计

## 目标

为博客新增 `/links/` 页面和顶栏入口。页面借鉴参考站的 88×31 友链墙结构，但沿用 Cavill's Blog 现有的配色、留白、边框、字体和响应式导航，不复制参考站的复古视觉皮肤。

## 顶栏

- 不删除、替换或隐藏任何现有入口。
- 桌面端与移动端菜单顺序固定为：Posts、Tags、Links、About、Archives、Search、Theme。
- Links 使用与 Posts、Tags、About 相同的文字链接、悬停效果、焦点样式和波浪线激活态。
- Archives、Search、Theme 的图标、标签和交互保持不变。

## 页面结构

`/links/` 复用现有的 `Layout`、`Header`、`Breadcrumb`、`Main` 和 `Footer`，保持站点级 SEO、主题和响应式行为一致。主体包含两个区块：

1. 页面标题、中文交换友链说明和 `Link to me` 面板。
2. `Friend Links` 友链墙；初始数据为空时显示简洁空状态。

建议文案为：“这里收集我常去的个人网站与博客。如果你也有自己的网站，欢迎通过 Email 联系我交换友链。”空状态为：“友链墙还是空的，期待第一位互联网邻居。”

## 自有按钮

- 目标地址：`https://blog.cavill.site/`
- 图片地址：`https://picgocloud.com/m/5c51c36c-707a-4905-b006-f9e368afb58c.gif`
- 固定尺寸：88×31
- 替代文本：`Cavill's Blog`
- 面板在桌面端横向排列，在窄屏上允许纵向堆叠；不增加复制按钮或客户端脚本。

## 友链数据与渲染

- 新增独立的本地数据模块，定义 `FriendLink` 类型和空的 `friendLinks` 数组。
- 每项包含 `name`、`url` 和 `imageUrl`，以后新增友链只需编辑数据模块。
- 非空时按照 88×31 原始尺寸紧凑换行，保留图片替代文本；页面不裁切、不拉伸按钮。
- 空数组时不渲染占位按钮，只显示带虚线边框的空状态。
- 远程图片加载失败时由浏览器展示 `alt` 文本，不增加运行时重试或占位脚本。

## 国际化与面包屑

- 导航字符串新增 `nav.links = "Links"`。
- 页面字符串新增 Links 标题、描述和空状态，保持现有英文 UI 类型完整；交换说明可以直接使用中文内容。
- 面包屑识别 `links`，显示与顶栏一致的 `Links` 标签。

## 验证

- 回归测试确认 Header 中现有入口全部保留，Links 位于 Tags 与 About 之间。
- 回归测试确认 `/links/` 复用站点布局、渲染自有按钮的准确属性，并对空数组显示空状态。
- 运行完整 Node 测试和生产构建。
- 在桌面端和移动端检查导航顺序、激活态、自有按钮尺寸以及空状态布局。
